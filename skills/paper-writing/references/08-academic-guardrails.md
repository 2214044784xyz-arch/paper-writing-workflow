# 学术写作护栏：什么时候不该「去 AI 味」

> 这一份是本 skill 的原创新增，不来自七个上游。上游都是通用写作/自媒体场景，直接照搬到论文会出事。

---

## 一、先承认一件事：论文的「机器感」有一半是规范

七个上游 skill 的共同假设是「自然、口语、有个人声音 = 好」。学术写作不是这样：

- **可复现**要求句式稳定。方法节每段都写成「我们采用 X 方法，以 Y 为样本，控制 Z」是优点，不是套路。
- **hedging 是学术诚实**。「可能」「在一定程度上」「初步证据表明」不是模糊，是认识论上的克制。删掉它们，论文会变得比数据更自信。
- **术语必须重复**。同一个变量从头到尾叫同一个名字，比换三种说法专业。
- **文献综述天然是枚举**。「第一类研究……第二类研究……」是分类，不是排比。

所以：**去 AI 味先定节，再定力度。** 全篇一个力度改下来，方法节会被改坏。

## 二、分节细则

### 摘要
- 保留：研究问题、数据、方法、核心系数/方向、一句含义。
- 可删：背景铺陈（「随着……的发展」）、「具有重要意义」。
- 常被误删：样本期与样本量——很多人为了压字数把它删了，这是硬伤。
- 自检：摘要里出现的每个结论，正文都要有对应。

### 引言
- 保留：事实性背景（带数据与引用）、研究缺口的三段式递进。
- 可删：宏大开场、政策口号、「众所周知」。
- 常被误删：缺口与贡献的对应关系——删套话时容易把「所以本文做什么」一起删掉。
- 自检：第三段结束前必须出现本文的研究问题。

### 文献综述
- 保留：「XX 等（年份）发现……」这种带主语的归因句式。
- 可删：「研究表明」后面不跟文献的模糊归因、「综上所述」。
- 常被误删：不同文献之间的关系词（一致/相反/补充）。删完会变成文献堆砌。
- 自检：每 3–4 篇文献之后要有一句「这说明什么/还没说明什么」。

### 假设与模型
- 只润色，不改命题。假设的方向（正/负）、调节变量、边界条件一个字都不能动。
- 「H1：内容曝光正向影响搜索转化」这种写法是规范的，不要改成「内容曝光会让搜索转化变好」。

### 方法
- 只删填充词、统一术语、统一时态。样本筛选步骤、变量构造公式、识别策略，一个字不改。
- 被动语态在这里往往是必要的（「样本按 X 标准剔除」），不要为了「多用主动语态」硬改成「我们剔除」。

### 结果
- 只做与表格对齐的表述统一。
- 「显著」只能用于统计显著，且要带 p 值/星号依据。
- 不要为了句子好看改系数的大小、方向、显著性描述。

### 讨论与结论
- 可以重写句式、压缩、去升华。
- 不可以：超出数据的因果断言、新增政策建议的论据、把「相关」写成「导致」。
- 好的结尾是「边界 + 一个未解问题」，不是「只有……才能……」。

## 三、套语白名单（这些不要当 AI 味删掉）

| 表达 | 为什么留 | 什么时候该删 |
| --- | --- | --- |
| 第一 / 第二 / 第三 | 分类枚举，学术规范 | 一段里出现 5 个以上、且内容不对应 |
| 一方面 / 另一方面 | 双向机制的标准写法 | 只出现一次且删掉不影响语义 |
| 本文认为 / 笔者认为 | 立场声明 | 一段出现三次以上 |
| 可能 / 或许 / 在一定程度上 | hedging | 用在已经有统计证据的结论上 |
| 显著 | 统计术语 | 非统计语境（「显著提升品牌形象」） |
| 综上 | 段落收束 | 每段都用 |
| 值得注意的是 | 提示读者 | 一段用两次，或后面跟的是废话 |

判断标准只有一条：**删掉之后，论证是否变弱？** 变弱就留，不变就删。

## 四、中文论文特有红线

1. **数字与单位**：不改写、不四舍五入、不换算。百分比与百分点不混用。
2. **引文标记**：`[12]`、`[12-14]`、`（张三，2020）` 原位保留；合并句子时不要把两个引文并成一个。
3. **变量与符号**：`Exposure_{i,t}`、`β₁`、`DID` 等保持原样，斜体/下标不丢。
4. **术语一致性**：「内容曝光」不能一段叫「内容触达」、一段叫「内容展示」。
5. **摘要不出现引文标记**（多数期刊要求），正文引文不能挪到摘要。
6. **结论不出现新数据**，只能复述已有结果。
7. **时态**：中文论文用「本研究发现」，不用「本文将发现」；英文摘要结果用过去时。
8. **人称**：中文经管类多用「本文」，不用「我们」；英文可用 we，但全篇统一。

## 五、中英差异（英文摘要/投稿时看）

| 维度 | 中文论文 | 英文论文 |
| --- | --- | --- |
| hedging | 「可能」「在一定程度上」 | may / suggest / consistent with |
| 连接词 | 首先/其次/最后 可以密集 | First/Second 一段最多一组 |
| 被动 | 方法节常用 | 方法节常用，但结果节倾向主动 |
| 第一人称 | 多用「本文」 | we 可接受，避免 I |
| 破折号 | 「——」用于解释，偶用 | em dash 极少，改写为从句 |
| 形容词 | 少用「显著/极大」 | 少用 crucial / pivotal / robust |

英文侧按 `references/01-humanizer-en.md` 的规则改；中文侧按 `references/02-humanizer-zh.md`。**不要拿中文清单去改英文**（比如中文忌讳「首先/其次」，英文的 First/Second 在方法节是正常的）。

## 六、过度去味的六个症状

改完发现自己中了三条以上，就回滚：

1. 方法节出现了「我们发现」这种叙事口吻。
2. 所有 hedging 都没了，结论比数据硬。
3. 每段长度变得差不多短——从「模板腔」变成了「短句腔」。
4. 术语开始同义替换（内容曝光/内容触达/内容展示混用）。
5. 文献综述变成了「A 说……B 说……C 说……」的流水账，关系词全没了。
6. 作者自己读不出这是自己写的。

回滚方法：从 `assets/revision-report.md` 的原句列恢复，只保留「理由」站得住的那几处。

## 七、和导师/审稿人怎么说

不要说「我用了去 AI 味工具」。说：

> 本轮修改做了三件事：统一了术语（内容曝光/搜索转化），删除了重复的过渡句 12 处，重写了摘要与结论的表述使其与表 3 的系数一致；方法节与结果节未改动实质内容。

这句话本身就是最好的「不像 AI 写的」证明。
