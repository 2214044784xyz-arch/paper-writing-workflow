# Prompt 包：7 条可直接复制的指令

> 每条都按「角色—输入—约束—输出格式—自检」五段写。中括号 `【】` 是要替换的槽位。
> 用法：复制 → 替换槽位 → 一次只喂一段（≤400 字）。

---

## A. 诊断（P0）

```text
你是中文学术论文的语言编辑。下面是论文的一节，请只做诊断，不要改写。

【粘贴段落】

请输出表格：| 位置(第几段/第几句) | 原文片段 | 痕迹类型 | 严重度(轻/中/重) | 建议动作 |
痕迹类型只能从这些里选：空泛评价 / 宏大开场 / 模糊归因 / 连接词轰炸 / 三段式排比 /
名词化 / 破折号滥用 / 列表化 / 绝对化 / 填充词 / 术语不一致。
最后给一句判断：这一节最该先动的是哪一类，为什么。
不要给改写版本，等我确认。
```

---

## B. 单段改写（P5+P6，核心工具）

```text
你是中文学术论文的改写编辑。请改写下面这段，遵守：

【不可动】数字、年份、样本量、系数、显著性、[n] 引文标记、变量名、英文术语、引号内原文。
【必须保留】所有 hedging（可能/在一定程度上/初步证据）、因果方向、结论边界。
【必须去掉】空洞评价（具有重要意义）、模糊归因（研究表明后不跟文献）、
  连接词轰炸（值得注意的是/综上所述/由此可见）、三段式排比、名词化（对X进行分析→分析X）。
【力度】= 中。同义重述 + 句序重排 + 删冗余，不新增任何事实，不改段落主张。
【字数】原文的 85%–110%。

【原段】
"""【粘贴】"""

输出三列：
1. 原句
2. 改句
3. 理由（只写「删了什么/合了什么/换了什么词性」，不写「更通顺」）

最后用一句话复述改后段落的主张，并指出有没有风险（比如某个限定被删掉了）。
```

力度档位替换：`轻` = 只删填充词与重复，不动句序；`中` = 允许重排与合句；`重` = 允许重写段落结构（仍不改事实）。

## C. 整篇去味（分批，P5）

```text
下面是论文的【第 X 节】，共 N 段。请按段处理，一次输出 3 段，等我回复「继续」再输出下一批。

规则同上一轮（不可动/必须保留/必须去掉/力度中/字数 85%–110%）。
每段输出：段号 | 改后全文 | 一句话改动说明 | 风险提示（若有）。

处理顺序：先删填充词与套话，再合并短句，最后调整段首句，使其直接给论点。
不要改动小标题编号。
```

## D. 审稿人视角（P7）

```text
你是《管理世界》/《营销科学学报》的匿名审稿人，方向是平台经济与消费者行为。
请审下面这一节，只挑「论证」的毛病，不挑语言。

【粘贴段落】

逐段回答三个问题：
1. claim（这段主张什么）是否明确？
2. evidence（证据是什么）是否支撑得住？有没有把相关当因果？
3. warrant（从证据到主张的推理）缺了哪一步？

输出：
- 必改（会导致拒稿）：≤3 条，每条指出段落号与缺失环节
- 建议改：≤5 条
- 不必改：1 条，说明哪里的写法其实是对的（避免过度修改）
```

## E. 开头测试（P2）

```text
请为这篇论文写 3 个版本的开头第一段，每版 ≤180 字：
A 版：从一组反差数据切入
B 版：从一个反常识的现象切入
C 版：从既有研究的分歧切入

三版都必须做到：第 3 句之前出现「既有研究没解决什么」，第 5 句之前出现「本文做什么」。
禁止：随着……的发展 / 在当今……背景下 / 众所周知。
写完后自评：哪一版最能让审稿人继续读下去，为什么（≤50 字）。
```

---

## F. 摘要压缩（P7）

```text
把下面这段摘要压到 280 字以内，保留：研究问题、数据与样本期、方法、核心结果（含方向）、
一句理论/实践含义。删掉所有背景铺陈与价值判断。

不许出现原文没有的结论；不许出现引文标记；不许用「具有重要意义」。
输出：压缩版 + 字数 + 被删掉的信息清单（防止误删样本信息）。

【原摘要】
"""【粘贴】"""
```

## G. Prompt 增强器（P8，来自 De-AI-Prompt-Enhancer 的思路）

```text
我原本的指令是：
"""【你写的 prompt】"""

请把它改写成一条更强的指令，补齐五件事：
1. 场景：这是给谁看的、发在哪（期刊/学位论文/开题）
2. 读者：审稿人最在意什么
3. 禁忌：绝对不能改的东西（数字、引文、术语、结论方向）
4. 验收标准：什么样的输出算合格（字数区间、必须保留的要素、自检项）
5. 输出格式：表格/三列/分段

改写后请标注：哪几句是你新增的、为什么加。
```

---

## 使用顺序建议

写新稿：E（开头）→ P1 立场 → P2 大纲 → B（逐段）→ F（摘要）
改旧稿：A（诊断）→ C（分批清理）→ B（重点段精修）→ D（审稿）→ F（摘要）
调 prompt：G → 再用 B/C/D

---

## 反模式（这些 prompt 会失败）

- 「帮我润色一下」——没有力度、没有禁区，模型只能靠猜。
- 「降 AIGC 率到 10% 以下」——不可验证，会诱导模型做无意义改写。
- 「写得更像人」——「人」是谁？要说「像本领域博士生的写法」。
- 一次贴 8000 字——模型会丢中段约束，只能处理首尾。
